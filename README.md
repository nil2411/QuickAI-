- Modular structure suitable for frontend AI integrations

## Language breakdown

The repository is primarily written in JavaScript, with some Shell and TypeScript files.

## Requirements

- Node.js 16+ (recommended)
- npm or yarn

## Installation

1. Clone the repository:

```bash
git clone https://github.com/nil2411/QuickAI-.git
cd QuickAI-
```

2. Install dependencies:

```bash
npm install
# or
# yarn install
```

## Development

Start a development server (if the project includes one):

```bash
npm run dev
# or
# npm start
```

If there are build scripts:

```bash
npm run build
```
